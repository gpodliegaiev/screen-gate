# ScreenGate

iOS app that helps fight procrastination by limiting time spent in distracting apps.

- **v1 — Hard daily limits:** pick apps and a daily time budget. Once it's used up, the apps are blocked until the end of the day. No "ignore limit," no extending the time.
- **v2 — Conditional unlock:** "useful first, entertainment later." Distracting apps unlock only after spending a set amount of time in a useful app (e.g., 20 min in Duolingo unlocks YouTube).

Built on Apple's Screen Time APIs (Family Controls, Managed Settings, Device Activity).
